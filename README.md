# Timesheet Automate
Application to Automate filling out Timesheet PDF's by directly accessing user's Google Calendar to extract work hours and autofill the timesheet.
![image](https://github.com/nandanasheri/timesheet-automate/assets/92496376/1970bdd5-f68e-472f-a4c7-8e61e7899076)

Once you log in through your Google Account, you can then fill out these details to specify your details and Time Period : 
![image](https://github.com/user-attachments/assets/f331929a-1ecb-45aa-bc1f-d6024c7fa60f)

And then you partiently wait, 
![image](https://github.com/user-attachments/assets/89421388-a8a6-4284-ab7b-b3bcc61d5ccf)

Until you see him pop up on your screen to tell you to check your Downloads!
![image](https://github.com/user-attachments/assets/88a3f686-464f-42fc-bfea-1bb8bade9253)

And there you go, a perfectly filled out Timesheet with the correct naming convention in the matter of seconds!

This app was built using:
Google Calendar API : [Documentation](https://developers.google.com/calendar/api/quickstart/nodejs) as well as pdf-lib Library within JavaScript [Tutorial](https://pspdfkit.com/blog/2023/how-to-fill-pdf-form-in-nodejs/#:~:text=In%20this%20tutorial%2C%20you%20learned,enhance%20efficiency%20in%20your%20workflows.), the application was built using Node.js, Express.js and React. Uses Google Oauth2 Authentication for Users to log in to the system using their Google Account.

Prerequisites Include : Node, React.js, Express and pdf-lib and Google Cloud Project.
